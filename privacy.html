Kebijakan Privasi — BGA (Baca Gali Alkitab)

Berlaku sejak: 16 Oktober 2026

Siapa yang memakai aplikasi ini

BGA adalah alat pribadi dan non-komersial. Aplikasi ini hanya dipakai oleh pemiliknya sendiri, dengan akun Google milik pemiliknya.

Data Google yang diakses

BGA memakai Google Drive API untuk mengunggah poster dan catatan pasal buatan BGA ke folder BGA di Google Drive pemilik, dan untuk menghapus versi lama dari berkas buatan BGA sendiri di folder itu. BGA tidak membaca, menganalisis, atau mengubah berkas lain di Google Drive.

Penyimpanan dan pembagian data

BGA tidak mengumpulkan data pribadi, tidak menjual data, dan tidak membagikan data kepada pihak ketiga. Token akses Google disimpan hanya di komputer dan server milik pemilik, dan dapat dicabut kapan saja di myaccount.google.com/permissions.

Pemakaian data Google

Pemakaian informasi yang diterima dari Google API mematuhi Google API Services User Data Policy, termasuk ketentuan Limited Use.
